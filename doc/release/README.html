VTB-TOOLS Metabox Nexus PlayerCap User Guide

This program reads the lyrics, song information and audio waveform of the track currently playing in music players on this PC, and can mirror the "lyric effects" view of NetEase Cloud Music, for use by lyric pages in OBS and similar tools.

一、系统要求

  • Windows 10 或 Windows 11，64 位。
  • 音频波形需要 Windows 10 2004 版（内部版本 19041）及以上。更低版本的系统上歌词功能不受影响，但不提供音频波形。

1. System requirements

  • Windows 10 or Windows 11, 64-bit.
  • The audio waveform requires Windows 10 version 2004 (build 19041) or later. On older systems lyrics are unaffected, but the audio waveform is not available.

二、开始使用

  1. 以管理员身份运行 Metabox-Nexus-PlayerCap.exe。读取播放器的内存需要管理员权限。
  2. 启动播放器并正常播放。播放器的启动先后不限，本程序会自动连接；播放器退出后，本程序等待其重新启动。
  3. 打开在线编辑器 https://playercap.cfg.vtb.tools/，OBS 页面的设置由此开始。
    在线编辑器可查看本程序的运行状态，为歌词、歌名/歌手、封面、波形、卡片、播放器等页面调整样式，并复制 OBS 浏览器源地址，填入 OBS 的浏览器源。
  4. 随包附带的以下三个 html 文件用于跳转到线上页面，使用时需要联网：
    • lyric_page.html：不带参数打开时进入在线编辑器；带参数时跳转到线上 v3 的同名页面。
    • lyric_display.html：歌词显示页，跳转到线上 v3 的同名页面。
    • effect_display.html：网易云音乐特效歌词镜像的显示页，跳转到线上 v3 的同名页面。
    线上 v3 是 3.x 版页面的冻结副本，参数与 3.x 相同，地址中的参数原样传递。
    OBS 的浏览器源既可指向这三个本地文件，也可直接填写线上地址。
    README.html 与 使用说明.html 即本说明，两者内容相同，无需联网即可打开。
  5. 本程序默认在 8765 端口提供服务。
  6. 首次运行时，本程序在其所在文件夹生成设置文件 config.yml，可用记事本打开修改。
    各项含义见文件中的注释；修改后须重新启动本程序方可生效。修改方法见如何修改配置与使用命令行参数。

2. Getting started

  1. Run Metabox-Nexus-PlayerCap.exe as administrator. Reading the players' memory requires administrator rights.
  2. Start the player and play music as usual. The player may be started before or after this program; this program connects to it automatically and, after the player exits, waits for it to be started again.
  3. Open the online editor at https://playercap.cfg.vtb.tools/, the starting point for setting up OBS pages.
    The editor shows this program's status, lets you adjust the style of pages such as lyrics, title/artist, cover, waveform, card and player, and provides an OBS browser source URL to copy into an OBS browser source.
  4. These three bundled HTML files redirect to online pages, so they need an internet connection:
    • lyric_page.html: opened without parameters, it opens the online editor; with parameters, it redirects to the page of the same name in the online v3.
    • lyric_display.html: the lyric display page; redirects to the page of the same name in the online v3.
    • effect_display.html: the display page of the NetEase Cloud Music lyric effects mirror; redirects to the page of the same name in the online v3.
    The online v3 is a frozen copy of the 3.x pages. It takes the same parameters as 3.x, and the parameters in the address are passed on unchanged.
    An OBS browser source can point to these three local files, or to the online address directly.
    README.html and 使用说明.html are this guide; both have the same content and open without an internet connection.
  5. This program serves on port 8765 by default.
  6. On first run, this program creates a settings file, config.yml, in its folder. You can edit it with Notepad.
    Each setting is explained in the comments in the file (written in Chinese); restart this program for changes to take effect. See Changing settings and using command-line options.

三、支持的播放器与版本

「版本不限定」指程序未对版本作判断，不代表所有版本均经过测试。

  • 全民K歌：版本不限定。
  • 网易云音乐：3.x 及以上的官网安装版。不支持低于 3 的版本与微软商店版。
  • QQ 音乐：只支持下方列出的已收录版本，按版本号的前两段对照。
    • 遇到未收录的版本时，本程序按最接近的已收录版本推测，读取结果可能有误。
    • 无法读取版本号时，按最新的已收录版本推测。
  • 酷狗音乐：20.1.22.27795 及以上（64 位）。不支持 10.x。
  • 汽水音乐：版本不限定。
  • Apple Music：版本不限定。
  • Spotify：版本不限定（实测 1.3.6.1921、1.3.10.2586），须为官网安装版，不支持微软商店版。
  • 酷我音乐：9.6.0.0（渠道后缀不限，实测 W1、UG1），须为官网安装版，不支持微软商店版。官网下载页 https://www.kuwo.cn/down 现提供的即为 9.6.0.0。

3. Supported players and versions

"Any version" means this program does not check the version; it does not mean every version has been tested.

  • WeSing (全民K歌): any version.
  • NetEase Cloud Music (网易云音乐): 3.x or later, official installer version. Versions below 3 and the Microsoft Store version are not supported.
  • QQ Music (QQ音乐): only the versions listed below, matched by the first two parts of the version number.
    • For an unlisted version, this program falls back to the closest listed version, and the data read may be incorrect.
    • If the version number cannot be read, it falls back to the newest listed version.
  • KuGou Music (酷狗音乐): 20.1.22.27795 or later (64-bit). 10.x is not supported.
  • Soda Music (汽水音乐): any version.
  • Apple Music: any version.
  • Spotify: any version (tested with 1.3.6.1921 and 1.3.10.2586); official installer version only, the Microsoft Store version is not supported.
  • Kuwo Music (酷我音乐): 9.6.0.0 (any channel suffix; tested with W1 and UG1); official installer version only, the Microsoft Store version is not supported. The official download page https://www.kuwo.cn/down currently provides 9.6.0.0.

Why some items are ⚠ or 🚫

Players marked 🚫 for local files do not support them yet; they are not repeated below.

WeSing
Translation 🚫: the platform has no translated lyrics.
NetEase Cloud Music
Word-by-word romanization is only available for songs with one syllable per character (such as Cantonese songs).
It can also mirror the NetEase Cloud Music "lyric effects" view. The sharpness depends on the size of the NetEase Cloud Music window: the larger the window, the sharper the image.
QQ Music
Local files ⚠: the lyrics follow the lyric link in QQ Music, whether you linked them manually or QQ Music matched them automatically. A local file with no linked lyrics has no lyrics. When QQ Music matches a local file to an online song, the lyrics still follow that file's link (except on the first play of the song and for a while after QQ Music renames it).
Online songs: for a song whose lyrics you changed in QQ Music (by linking local lyrics, or by picking one in "Search lyrics"), the lyrics match what QQ Music shows. This works only on versions 22.16, 22.22, 22.26, 22.31, 22.41, 22.60, 22.71, 22.76, 22.81 and 22.82.
KuGou Music
Local files ⚠: the lyrics follow KuGou, taken in this order:
  1. the lyrics you linked manually in KuGou;
  2. the lyrics KuGou matched automatically;
  3. if there are none, a search by file name, which may find nothing or the wrong lyrics.
Online songs, unlinking and lyric timing adjustment: both online and local songs follow any local lyric file you link manually in KuGou, "Unlink lyrics" (clears lyrics immediately and stays empty while KuGou remains unlinked; resumes once you link or select lyrics again), and timing offsets set in KuGou's lyric speed/offset adjustment (combined with kugou-offset). This works in real time on recognized versions (currently 20.1.22.27795); unrecognized versions fall back automatically to database mode.
Soda Music
Romanization ⚠: the platform has none; this program borrows KuGou Music's romanization, matched by title and duration. Coverage and accuracy are not guaranteed.
Apple Music
Word-by-word lyrics, line-by-line lyrics and translation ⚠:
  • Keep the Apple Music lyrics panel open. Apple Music does not load lyrics while the panel is closed; they appear once it is opened.
  • After a song change, lyrics may take a few seconds to appear, and occasionally they are missing or belong to another song.
  • Word-by-word lyrics are only available for songs the platform provides them for.
Romanization 🚫: the platform has none.
Cover ⚠: the cover image is available, but not a cover URL; after a song change the cover may appear a little later.
Spotify
Word-by-word lyrics 🚫: the platform only provides line-by-line lyrics.
Translation and romanization 🚫: the platform has none.
Spotify has to run with the debug port and related launch options; see "Why does this program restart NetEase Cloud Music, Spotify or Kuwo Music?" in the FAQ.
Kuwo Music
Word-by-word lyrics ⚠: only for songs with valid per-word timing; other songs fall back to line-by-line.
Translation ⚠: only the one bilingual lyric format that has been tested; other formats give no translation.
Romanization 🚫: not provided at present.
Position and seeking ⚠: the position is read from Kuwo's memory; when it cannot be read, this program treats Kuwo as being in the waiting state.

五、常见问题

自动更新失败时如何处理？

本程序启动时检查新版本并自动更新：

  • 先测速，选择较快的下载线路；
  • 下载过慢或出错时，自动切换线路。

若仍失败，请依次尝试：

  1. 按窗口中的提示按 R 键重试。
  2. 稍后重新启动本程序。
  3. 从发行版页面手动下载：关闭本程序，下载最新版的 Metabox-Nexus-PlayerCap.zip（或单独的 Metabox-Nexus-PlayerCap.exe），解压后覆盖原有文件。

压缩包中不含 config.yml，原有设置不受影响。

部分歌曲为何没有逐字、翻译或音译歌词？

这取决于音乐平台是否为该歌曲提供；平台未提供的，本程序无法获取。

各播放器自身的限制见各播放器的支持情况。

逐字音译的提供情况：

  • 全民K歌、QQ 音乐、酷狗音乐、汽水音乐提供；
  • 网易云音乐仅在一字一音的歌曲（如粤语歌）上提供；
  • Apple Music、Spotify、酷我音乐不提供。

日语歌词汉字上方的假名注音（振假名）：仅 QQ 音乐在平台歌词自带该注音时提供。

播放本机音乐文件时应使用哪个播放器？

酷狗音乐与 QQ 音乐部分支持。

酷狗音乐：歌词与酷狗保持一致，按以下顺序获取：

  1. 在酷狗中手动关联的歌词；
  2. 酷狗自动匹配的歌词；
  3. 以上均无时按文件名搜索，可能无法搜到，或结果不准确。

QQ 音乐：歌词与 QQ 音乐中的关联保持一致，取在 QQ 音乐中手动关联或由 QQ 音乐自动匹配的歌词；没有关联的本地文件无法获取歌词。QQ 音乐将本地文件匹配为在线歌曲时，歌词同样与该文件的关联保持一致（首次播放该曲、QQ 音乐改名之后的一段除外）。

其他播放器播放本地文件时无法获取歌词。

为何不支持微软商店版的播放器？如何处理？

网易云音乐、Spotify、酷我音乐须由本程序带调试参数重新启动方可取词，微软商店版无法以这种方式启动。

检测到商店版时，本程序跳过该播放器，并在窗口中提示改用官网安装版。

处理方法：

  1. 卸载商店版。
  2. 安装官网安装版：
    • 网易云音乐：https://music.163.com/download/pc/latest
    • Spotify：https://download.scdn.co/SpotifySetup.exe
    • 酷我音乐：https://www.kuwo.cn/down（官网下载页）
  3. 安装完成后无需重启本程序，稍候即会自动连接。

Apple Music 仅有微软商店版；本程序只读取其内存，不会重启该播放器，因此不受影响。

本程序为何会重启网易云音乐、Spotify、酷我音乐？

本程序通过这几个播放器的调试端口取词，而调试端口只能在播放器启动时通过启动参数开启。

检测到播放器未带所需参数运行时，本程序会将其关闭并带参数重新启动，正在播放的歌曲会中断。

此后若用户自行关闭播放器并以常规方式重新打开，本程序会再次执行上述操作。

  • 网易云音乐、Spotify：若已设置开机自启，本程序会将参数补入自启项，此后经开机自启启动的播放器无需再重启。
  • 酷我音乐：仅已验证的渠道版本（W1、UG1）会被自动重启；其他渠道版本须由用户自行以启动参数 --remote-debugging-port=9224 启动酷我。

酷狗音乐首次接入时，本程序会修补酷狗的文件以开启调试端口，可能弹出管理员授权提示（UAC）并重启酷狗。

对于未适配的酷狗版本，本程序不会强行修改。

Apple Music 无歌词时如何处理？

须保持 Apple Music 的歌词面板处于打开状态。

面板关闭时 Apple Music 不加载歌词，打开面板后即可获取。

换歌后歌词可能延迟数秒出现。

任务管理器中为何有两个本程序的进程？

以下两种情况会多出一个进程：

  • 有页面使用音频波形时，本程序会另启动一个自身的子进程以捕获声音。该进程不弹出授权提示，无需也不应手动启动；波形连接全部断开或本程序退出后自动结束。
  • 程序文件名不是 Metabox-Nexus-PlayerCap.exe 时，本程序会将自身复制为该文件名后启动。此时以及自动更新完成后，最初启动的进程将保留至本程序退出。

音频波形无变化时如何排查？

  • 系统须为 Windows 10 2004 版（内部版本 19041）及以上。
  • 播放器的声音输出设为 ASIO 或 WASAPI 独占模式时，声音绕过系统混音，本程序无法捕获。

歌词早于或晚于歌声时如何调整？

在 config.yml 中调整歌词延迟，单位为毫秒，正值延后，负值提前。

  • 各播放器优先使用自己的 <名字>-offset，未设置时使用全局的 offset。
  • 自动生成的 config.yml 已为多个播放器设定了各自的值，调整时应修改对应播放器的项，例如网易云音乐的 cloudmusicv3-offset。

修改后重新启动本程序。

各播放器在设置中的名称：全民K歌 wesing、网易云音乐 cloudmusicv3、QQ 音乐 qqmusic、酷狗音乐 kugou、汽水音乐 sodamusic、Apple Music applemusic、Spotify spotify、酷我音乐 kuwo。

同时运行多个播放器时显示哪一个？

默认优先显示全民K歌（设置项 prior-player）：

  • 全民K歌播放时，始终显示全民K歌；
  • 全民K歌暂停超过 15 秒（设置项 prior-player-expire）或停止播放后，切换为其他播放器。

修改方法：在 config.yml 中修改以下两项，保存后重新启动本程序。

  • prior-player：优先播放器，每行一个，写作 - 名字。文件中已列出其余播放器并以 # 注释，删去行首的 # 即加入，在行首加上 # 即去除。全部注释掉时不起作用，仍优先全民K歌；不设优先播放器须写作 prior-player: []。
  • prior-player-expire：暂停多少秒后切换，例如改为 30。不要设为 0：这会关闭全部等待时限，暂停的播放器将一直占用显示。

各播放器的名字见上一问。详细说明见如何修改配置与使用命令行参数。

升级后设置为何发生变化？

新版本可能自动换算或重建 config.yml。

原文件会在同一文件夹中保留一份备份，文件名以 config.backup- 开头。

重建时，需要重新填写的设置会列在本程序的窗口中。

5. FAQ

Automatic update failed. What should I do?

At startup this program checks for a new version and updates itself:

  • it first tests download speed to pick the faster route;
  • if the download is too slow or fails, it switches to another route.

If it still fails, try these in order:

  1. Press R to retry when the window prompts you.
  2. Restart this program later.
  3. Download it manually from a release page: close this program, download the latest Metabox-Nexus-PlayerCap.zip (or Metabox-Nexus-PlayerCap.exe on its own), and extract it over the existing files.

The zip does not contain config.yml, so your settings are kept.

Why do some songs have no word-by-word lyrics, translation or romanization?

It depends on whether the music platform provides them for that song; what the platform does not provide, this program cannot obtain.

For the limits of each player, see What each player provides.

Word-by-word romanization:

  • provided by WeSing, QQ Music, KuGou Music and Soda Music;
  • NetEase Cloud Music has it only for songs with one syllable per character (such as Cantonese songs);
  • Apple Music, Spotify and Kuwo Music do not have it.

Furigana (kana readings above kanji in Japanese lyrics): provided by QQ Music only, for songs whose platform lyrics include them.

Which player should I use for local music files?

KuGou Music and QQ Music, both only partly.

KuGou Music: the lyrics follow KuGou, taken in this order:

  1. the lyrics you linked manually in KuGou;
  2. the lyrics KuGou matched automatically;
  3. if there are none, a search by file name, which may find nothing or the wrong lyrics.

QQ Music: the lyrics follow the lyric link in QQ Music, whether you linked them manually or QQ Music matched them automatically. A local file with no linked lyrics has no lyrics. When QQ Music matches a local file to an online song, the lyrics still follow that file's link (except on the first play of the song and for a while after QQ Music renames it).

Other players provide no lyrics for local files.

Why is the Microsoft Store version of a player not supported, and what can I do?

NetEase Cloud Music, Spotify and Kuwo Music have to be restarted by this program with debug options before lyrics can be read, which is not possible with the Microsoft Store version.

When it finds a Store version, this program skips it and shows a message in its window suggesting the official installer version.

What to do:

  1. Uninstall the Store version.
  2. Install the official installer version:
    • NetEase Cloud Music: https://music.163.com/download/pc/latest
    • Spotify: https://download.scdn.co/SpotifySetup.exe
    • Kuwo Music: https://www.kuwo.cn/down (official download page)
  3. You do not need to restart this program afterwards; it connects automatically after a short while.

Apple Music only exists as a Microsoft Store app; this program only reads from it and never restarts it, so it is not affected.

Why does this program restart NetEase Cloud Music, Spotify or Kuwo Music?

This program reads lyrics from these players through their debug port, which can only be opened with launch options when the player starts.

When it finds one of them running without the required options, this program closes it and opens it again with the options, which interrupts the song that is playing.

If the player is later closed and reopened without these options, the same restart is performed again.

  • NetEase Cloud Music and Spotify: if the player is set to start with Windows, this program adds the options to that startup entry, so the player no longer needs a restart when it starts that way.
  • Kuwo Music: only the verified channel builds (W1, UG1) are restarted automatically; other builds must be started by yourself with the launch option --remote-debugging-port=9224.

When KuGou Music is connected for the first time, this program patches a KuGou file to open its debug port; this may show an administrator prompt (UAC) and restarts KuGou.

KuGou versions that have not been adapted are never modified.

Apple Music shows no lyrics.

Keep the Apple Music lyrics panel open.

Apple Music does not load lyrics while the panel is closed; they appear once it is opened.

After a song change, lyrics may take a few seconds to appear.

Why are there two processes of this program in Task Manager?

There is one more process in either of these cases:

  • When a page uses the audio waveform, this program starts a child process of itself to capture the sound. It does not show any prompt and should not be started manually; it exits when all waveform connections close or this program exits.
  • If the program file is not named Metabox-Nexus-PlayerCap.exe, this program copies itself to that name and starts the copy. In that case, and after an automatic update, the process started first stays until this program exits.

The audio waveform does not move.

  • Windows must be Windows 10 version 2004 (build 19041) or later.
  • If the player outputs through ASIO or WASAPI exclusive mode, the sound bypasses the Windows mixer and this program cannot capture it.

The lyrics are ahead of or behind the singing.

Adjust the lyric delay in config.yml, in milliseconds: positive values delay the lyrics, negative values bring them forward.

  • Each player first uses its own <name>-offset and falls back to the global offset when that is not set.
  • The generated config.yml already sets values for several players, so change the entry for the player in question, for example cloudmusicv3-offset for NetEase Cloud Music.

Restart this program afterwards.

Player names in the settings: WeSing wesing, NetEase Cloud Music cloudmusicv3, QQ Music qqmusic, KuGou Music kugou, Soda Music sodamusic, Apple Music applemusic, Spotify spotify, Kuwo Music kuwo.

Several players are open. Which one is shown?

By default WeSing has priority (setting prior-player):

  • while WeSing is playing, it is always shown;
  • after it has been paused for more than 15 seconds (setting prior-player-expire) or stops playing, another player takes over.

To change this, edit these two settings in config.yml, save, and restart this program.

  • prior-player: the priority players, one per line, written as - name. The other players are already listed in the file and commented out with #; delete the leading # to add a player, or put # in front of a line to remove it. Commenting out every line has no effect, and WeSing keeps priority; for no priority player, write prior-player: [].
  • prior-player-expire: how many seconds of pause before switching, for example 30. Do not set it to 0: that turns off every waiting limit, and a paused player keeps the display indefinitely.

The player names are listed in the previous question. For details, see Changing settings and using command-line options.

My settings changed after an upgrade.

A new version may convert or rebuild config.yml automatically.

The original file is kept as a backup in the same folder; its name starts with config.backup-.

When the file is rebuilt, the settings you need to fill in again are listed in this program's window.

八、如何修改配置与使用命令行参数

设置有两种写法：写在 config.yml 中，或在启动本程序时以命令行参数给出。两处都写了的，以命令行参数为准；都没写的，使用内置默认值。

修改配置
  • 位置：本程序所在文件夹中的 config.yml，首次运行时自动生成。本程序窗口顶部「配置文件」一行显示实际读取的文件。
  • 打开方式：用记事本打开，修改后保存。
  • 写法：每项一行，写作 名字: 值，冒号后留一个空格。行首带 # 的是注释，不生效；删去行首的 # 即启用该行。
  • 分区：文件前半部分是全局设置，如 addr（监听地址）、offset（歌词延迟）、prior-player（优先播放器）；后半部分按播放器分段，设置项以播放器的名字开头，如 kugou-offset。其中 名字-offset、名字-poll、名字-idle-hide、名字-audio-normalize 没有写或已注释掉时，分别使用全局的 offset、poll、per-player-idle-hide、audio-normalize。
  • 生效：保存后须重新启动本程序。
  • 升级时 config.yml 可能被自动换算或重建，见常见问题「升级后设置为何发生变化？」。
使用命令行参数
  • 参数的名字与 config.yml 中的设置项相同，前面加 -，如 -offset、-kugou-offset。在命令提示符中运行 Metabox-Nexus-PlayerCap.exe -h 可列出全部参数。
  • 写作 -参数 值 或 -参数=值，如 -poll 50；负值照写，如 -offset -200 或 -offset=-200。
  • 开关类参数（-audio-normalize、-song-info-keep-first、-名字-audio-normalize）只写参数名即为开，写作 -参数 false 或 -参数=false 为关。
  • 优先播放器写作以逗号分隔的列表，如 -prior-player wesing,kugou；写作 -prior-player "" 为不设优先播放器。
  • 参数名写错，或有不属于任何参数的词（如漏了横线的 offset -200）时，本程序报错并列出全部参数后退出，不会忽略。
  • 4.0 起 offset 的方向与 3.x 相反。升级时 config.yml 中的值会自动换算，写在快捷方式或脚本中的 -offset、-名字-offset 不会换算，须自行改为相反数。

在快捷方式中添加参数：右键单击本程序的快捷方式，选择「属性」，在「目标」一栏的程序路径之后加一个空格，再写参数，例如：

"C:\PlayerCap\Metabox-Nexus-PlayerCap.exe" -offset -300 -prior-player kugou

由 OBS 的自启插件等其他程序启动本程序时，若该程序可设置启动参数，写法相同。

8. Changing settings and using command-line options

A setting can be written in config.yml, or given as a command-line option when this program starts. If both are given, the command-line option wins; if neither is, the built-in default is used.

Changing settings
  • Location: config.yml in this program's folder, created on first run. The "Config file" line (配置文件 in Chinese) at the top of this program's window shows the file actually read.
  • Opening: open it with Notepad, edit, and save.
  • Format: one setting per line, written as name: value with a space after the colon. Lines starting with # are comments and have no effect; delete the leading # to enable a line.
  • Sections: the first part of the file holds the global settings, such as addr (listen address), offset (lyric delay) and prior-player (priority players); the rest is grouped by player, with each setting starting with the player's name, such as kugou-offset. When name-offset, name-poll, name-idle-hide or name-audio-normalize is missing or commented out, the global offset, poll, per-player-idle-hide or audio-normalize is used respectively.
  • Applying: restart this program after saving.
  • An upgrade may convert or rebuild config.yml automatically; see "My settings changed after an upgrade." in the FAQ.
Using command-line options
  • Options have the same names as the settings in config.yml, preceded by -, such as -offset and -kugou-offset. Run Metabox-Nexus-PlayerCap.exe -h in Command Prompt to list all options.
  • Write -option value or -option=value, such as -poll 50; negative values are written as they are, such as -offset -200 or -offset=-200.
  • Switches (-audio-normalize, -song-info-keep-first, -name-audio-normalize) are turned on by the option name alone, and off by -option false or -option=false.
  • Priority players are a comma-separated list, such as -prior-player wesing,kugou; -prior-player "" means no priority player.
  • If an option name is misspelled, or a word is not part of any option (such as offset -200 without the dash), this program reports it, lists all options and exits; nothing is silently ignored.
  • From 4.0 on, offset works in the opposite direction to 3.x. On upgrade the values in config.yml are converted automatically, but -offset and -name-offset written in a shortcut or script are not; change their sign yourself.

To add options to a shortcut: right-click the shortcut to this program, choose "Properties", and in the "Target" box add a space after the program path, then the options, for example:

"C:\PlayerCap\Metabox-Nexus-PlayerCap.exe" -offset -300 -prior-player kugou

When this program is started by another program, such as an OBS autostart plugin, use the same format if that program lets you set launch options.
